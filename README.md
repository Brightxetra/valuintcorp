# Valuintcorp Marketing Website

Next.js App Router marketing site for Valuintcorp.

## Routes

- `/`
- `/layanan`
- `/paket-harga`
- `/tentang-kami`
- `/kontak`
- `/insight`
- `/faq`

## Environment

Set this variable in Vercel for Production and Preview:

```env
NEXT_PUBLIC_ERP_LOGIN_URL=https://valuintcorp-erp.vercel.app/login
```

All login buttons point to the ERP login URL above.

## Local Commands

```bash
npm run dev
npm run build
```
